# AI Blog Writing Prompt Template for Money Pages

Copy and customize this prompt for generating money page articles.

---

## PROMPT TEMPLATE

```
You are an expert content writer specializing in affiliate product review articles. Create a comprehensive money page article following this exact structure:

## ARTICLE TOPIC
[Insert your topic here, e.g., "Best Electric Bikes for 2025"]

## MAIN KEYWORD
[Insert main keyword, e.g., "best electric bikes"]

## CONTENT STRUCTURE

### 1. SEO & METADATA (The 3 Kings)
- **SEO Title**: Start with main keyword, add modifier (e.g., "2025", "Top Picks", "Ultimate Guide"), keep under 60 characters
- **H1**: Different from SEO title, include keyword variation, natural and engaging
- **Meta Description**: Under 155 characters, include main keyword naturally, compelling and informative

### 2. INTRODUCTION (3 paragraphs)
- Paragraph 1 (100-200 words): Engaging hook, establishes the problem/need
- Paragraph 2 (100-200 words): Builds authority, explains testing methodology
- Paragraph 3 (100-200 words): Sets expectations, previews what reader will learn
- Use natural keyword usage throughout (no stuffing)

### 3. PRODUCTS SECTION (7-10 products required)

For EACH product, provide:

**Product Name Format**: "[Product Name] - [Descriptive Subtitle]"
- Example: "Aventon Level 3 - Best Overall Electric Bike"

**Required Fields:**
- **Rank**: 1, 2, 3, etc.
- **Description**: 2-3 engaging sentences about the product
- **Key Features** (format as "Label: Value"):
  - Motor: [specification]
  - Battery: [specification]
  - Range: [specification]
  - Weight: [specification]
  - Best For: [target audience/use case]
- **Performance Ratings** (5 categories, 0-10 scale with weights):
  - Ride Quality (weight: 25%)
  - Range (weight: 25%)
  - Hills (weight: 25%)
  - Interface (weight: 15%)
  - Assembly (weight: 10%)
- **Performance Notes**: 2 detailed paragraphs (100-150 words each) with real-world testing insights
- **Who It's Best For**: 1 paragraph describing target audience
- **Pros**: 4-5 specific bullet points
- **Cons**: 2-3 specific bullet points
- **Price Badge**: Display price (e.g., "Around $1,899")
- **Average Rating**: 4.0-5.0 (for star display)

**Writing Style for Products:**
- Conversational, expert tone
- Real-world testing insights
- Specific examples and use cases
- Honest pros and cons
- No generic marketing fluff

### 4. COMPARISON TABLE
Create a quick comparison table with all products showing:
- Model name
- Price
- Average rating
- Affiliate link placeholder

### 5. BUYER'S GUIDE (4-6 sections)

Each section should have:
- **H3 Title**: Specific, educational topic
- **2-3 Paragraphs**: 100-200 words each, educational content
- **3-5 Bullet Points**: Key takeaways

**Suggested Topics:**
- Understanding product classes/types
- Key specifications explained
- What to consider before buying
- Common mistakes to avoid
- Making your final decision

**Writing Style:**
- Educational, helpful (not sales-focused)
- Addresses common buyer questions
- Natural keyword usage
- Actionable advice

### 6. FAQ SECTION (5-8 questions)

Each FAQ:
- **Question**: Natural, conversational (what users actually ask)
- **Answer**: 2-3 paragraphs, comprehensive but concise
- Include main keyword naturally in answers

**Common FAQ Topics:**
- Product differences/classes
- Pricing/value questions
- Usage scenarios
- Maintenance/durability
- Legal/regulatory questions

### 7. INTERNAL LINKS (2-5 links)
- Link to related articles in the same category/cluster
- Use natural anchor text variations (not exact match keywords)
- Include brief descriptions

## WRITING REQUIREMENTS

1. **Tone**: Conversational expert, helpful, honest (not salesy)
2. **Keyword Usage**: Natural integration, never stuffed
3. **Word Counts**: Follow specified ranges exactly
4. **SEO Compliance**: 
   - Only ONE H1 per page
   - Each product is an H2
   - Pros/Cons/Features are H3 under each product
   - Buyer's guide sections are H3 under H2
5. **Content Quality**: Real insights, specific examples, no generic fluff
6. **Product Count**: Minimum 7 products, ideally 8-10

## OUTPUT FORMAT

Provide the content in a structured format matching the money page template:
- All text content (no placeholders)
- Proper formatting for arrays and objects
- Ready to insert into content management system

Begin writing the article now.
```
